Pertanyaan Laporan
1. Mengapa telepon bukan kuantitas number?
Nomor telepon bukan kuantitas angka (number) karena nomor telepon tidak mewakili suatu nilai numerik atau jumlah yang bisa dihitung. Dalam dunia pemrograman dan analisis data, nomor telepon dikategorikan sebagai teks (string).
2. Apa beda label pilihan dan legend kelompok?
Label Pilihan : Teks yang menjelaskan arti dari satu opsi spesifik dalam elemen masukan (seperti radio button atau checkbox).
Label Legend : Teks yang berfungsi sebagai judul untuk sekumpulan pilihan yang saling berhubungan.
3. Apa beda id dan name ?
ID : Nilai id tidak boleh sama dengan elemen lain di dalam satu halaman web yang sama.
Card : Nilai name boleh sama pada beberapa elemen, contohnya pada tombol radio (radio button) untuk mengelompokkannya.
4. Apa yang terjadi pada checkbox tidak dicentang?
Ketika sebuah checkbox tidak dicentang, perilaku dan nilainya akan berubah tergantung pada apakah Anda melihatnya dari sudut pandang pengguna halaman web atau dari sudut pandang pemrograman


fungsi fungsi
1. fieldset: Digunakan untuk mengelompokkan beberapa bagian form yang saling berkaitan agar lebih rapi dan mudah dipahami.
2. legend: Digunakan untuk memberi judul pada kelompok form yang dibuat dengan fieldset.
3. label: Digunakan untuk memberi keterangan pada bagian input, supaya pengguna tahu data apa yang harus diisi atau dipilih.
4. input: Digunakan sebagai tempat pengguna mengisi atau memilih data, seperti nama, email, nomor telepon, radio, dan checkbox.
